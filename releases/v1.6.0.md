# RHYFT v1.6.0 — Atualizar playlists pelo histórico

Windows e Android agora permitem atualizar uma playlist já migrada pela ação **Retomar / atualizar** do histórico local. Depois de adicionar músicas à origem, use essa ação para enviar as faixas que faltam para a mesma playlist de destino.

## Windows e Android

- **Retomar / atualizar** disponível no histórico, incluindo migrações concluídas.
- A origem é lida novamente para encontrar músicas adicionadas desde a última migração.
- As faixas atuais do destino são conferidas antes dos novos envios, evitando repetir músicas já presentes.
- O progresso identifica a origem e o sentido da migração para retomar a playlist correta. A conta de destino também é vinculada quando a plataforma fornece um identificador estável.
- Checkpoints antigos são preservados. Quando o registro ainda não identifica a origem, o app solicita seu link uma vez para vincular a retomada.
- Autenticação, busca de músicas, revisão manual e controles de migração continuam disponíveis.

## Como atualizar

1. Adicione músicas à playlist de origem.
2. Abra o RHYFT e conecte as contas usadas na migração.
3. No histórico, escolha **Retomar / atualizar** para o destino desejado.
4. Confira o resultado e revise as correspondências que precisarem da sua escolha.

A atualização é iniciada por você. Músicas removidas da origem permanecem no destino.

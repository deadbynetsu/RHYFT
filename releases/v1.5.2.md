# RHYFT v1.5.2 — More room for the migration log

Atualização focada na experiência do app Windows, principalmente quando a janela está maximizada em monitores com pouca altura útil, como 1366×768.

## Windows

- A área de **registro/log da migração ficou significativamente maior**.
- O log agora parte de uma altura visual maior e continua expansível com o tamanho da janela.
- Redução de espaços verticais excessivos no cabeçalho, cartões de conta, formulário de migração e painel de progresso.
- Botões principais ficaram levemente mais compactos sem perder legibilidade.
- O rodapé foi reorganizado em **uma única linha**, mantendo idioma e links sociais e liberando mais altura para o conteúdo importante.
- A interface preserva o mesmo visual, recursos, branding e controles da v1.5.1.

## Android

- Nenhuma mudança funcional específica nesta atualização.
- O APK é recompilado como **v1.5.2** para manter o versionamento oficial alinhado entre as plataformas.
- Identificador do aplicativo, dados e preferências existentes são preservados.

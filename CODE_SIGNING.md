# Code signing policy

RHYFT is an open-source project distributed under the MIT License. Official Windows release binaries are built from the public source code in this repository using GitHub Actions.

RHYFT is applying to SignPath Foundation for code signing. Once the onboarding is complete, official Windows release binaries will be submitted for signing only when they are produced by the repository's automated release workflow.

**Free code signing provided by SignPath.io, certificate by SignPath Foundation.**

## Project roles

RHYFT is currently maintained by a single independent developer:

- **Committer and reviewer:** [deadbynetsu](https://github.com/deadbynetsu)
- **Approver:** [deadbynetsu](https://github.com/deadbynetsu)

Changes to source code and build workflows are kept in the public GitHub repository. Signing requests will only be approved for official RHYFT release artifacts built from this repository.

## Release provenance

Official Windows binaries are generated by GitHub Actions from the source code and build scripts stored in this repository. The Windows workflow performs a startup smoke test and a Microsoft Defender scan before publishing release artifacts.

Official downloads are available from:

- https://github.com/deadbynetsu/RHYFT/releases/latest

## Privacy

Privacy policy:

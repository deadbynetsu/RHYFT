Termos de Serviço

Última atualização: 7 de outubro de 2026.

1. Sobre o projeto

O RHYFT é um projeto gratuito e open source criado para auxiliar na transferência de playlists entre Spotify e YouTube Music.

2. Projeto independente

O RHYFT não é afiliado, patrocinado ou endossado por Spotify, Google, YouTube ou YouTube Music. As marcas citadas pertencem aos seus respectivos proprietários.

3. Uso das suas contas

Você é responsável por usar contas às quais possui acesso legítimo e por respeitar os termos das plataformas conectadas. As autorizações concedidas ao RHYFT devem ser utilizadas apenas para operações iniciadas por você.

4. Dependência de serviços externos

O funcionamento depende de APIs, limites, políticas e disponibilidade de terceiros. Na Web, a busca de músicas consulta o catálogo público do YouTube Music de forma anônima pelo servidor Netlify; o acesso às suas playlists continua usando OAuth e as APIs oficiais. Mudanças realizadas por Spotify, Google ou YouTube podem alterar, limitar ou interromper temporariamente partes do serviço.

5. Correspondência de músicas

A identificação de versões equivalentes é automatizada sempre que possível, mas catálogos podem conter remixes, versões ao vivo, covers e gravações com metadados semelhantes. A versão Web separa resultados de baixa confiança para decisão manual. Ainda assim, revise a playlist final.

6. Disponibilidade e garantias

O software é fornecido “como está”, sem garantia de disponibilidade contínua, ausência de erros ou correspondência perfeita de todos os itens. Isso não limita direitos que a legislação aplicável não permita excluir.

7. Limites das plataformas

A busca pública no YouTube Music e as APIs de Spotify e YouTube têm limites próprios. A busca Web no catálogo público não usa a cota de busca da YouTube Data API, mas ler, criar e modificar playlists ainda consome as cotas das APIs autenticadas. Uma migração pode ter buscas indisponíveis ou ser temporariamente interrompida quando uma plataforma limitar requisições. O progresso salvo permite retomar; quando a busca de uma faixa falha, você também pode indicar o link do vídeo.

8. Privacidade

O tratamento de tokens e demais informações necessárias ao funcionamento está descrito na Política de Privacidade.

9. Código-fonte e licença

O código do projeto está disponível no GitHub e é distribuído conforme a licença MIT presente no repositório.

10. Alterações

Estes termos podem ser atualizados para acompanhar mudanças no projeto ou nas plataformas externas. A versão vigente é a publicada nesta página.

11. Contato

Para dúvidas ou problemas, utilize o repositório oficial: GitHub Issues.

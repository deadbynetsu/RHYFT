# Suporte

Para dúvidas de uso, problemas de instalação ou comportamento inesperado do RHYFT:

1. confira a [Release mais recente](https://github.com/deadbynetsu/RHYFT/releases/latest);
2. procure uma issue existente;
3. se não encontrar, abra um novo relato usando os templates do repositório.

Ao pedir ajuda, informe a plataforma, a versão do RHYFT e passos para reproduzir o problema.

Não publique tokens, cookies, Client Secrets, credenciais ou dados pessoais.

Para vulnerabilidades de segurança, consulte [SECURITY.md](./SECURITY.md) em vez de abrir uma issue com detalhes exploráveis.
